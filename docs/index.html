agent-toolkit

One small, single-file tool for AI agent builders, every week.

The series

  1. Week 1Live

    Budget guard

    Long agent tasks spend tokens, money, and tool calls before anyone looks. The guard takes a budget for the task and answers before each costly step: continue, warn near the limit, or stop and ask a human. Spend sits in a local JSON ledger, so a restart does not wipe the total.

  2. Week 2Live

    Handoff checker

    When one agent hands work to the next, the payload often drops the goal, the owner, the budget left, or a file it cites. The checker reads a JSON or Markdown handoff and answers ready, needs-fixes, or blocked, with the exact lines to change.

Week 1 quickstart

Python 3.9 or newer. No packages to install. From a clone of the repo:

python3 budget_guard.py open fix-flaky-test \
  --max-tokens 2500 --max-cost-usd 0.02 \
  --max-tool-calls 4

python3 budget_guard.py check fix-flaky-test \
  --tokens 600 --tool-calls 1

python3 budget_guard.py record fix-flaky-test \
  --tokens 600 --tool-calls 1 --note read_failures

python3 budget_guard.py status fix-flaky-test

The same open, check, record, and status operations are a local MCP server: python3 budget_guard.py serve. python3 demo.py runs a short agent loop that gets warned, then stopped.

Week 2 quickstart

Python 3.9 or newer. No packages to install. From a clone of the repo:

python3 handoff_checker.py template --output handoff.md

python3 handoff_checker.py check handoff.md

python3 handoff_checker.py explain

The check answers ready, needs-fixes, or blocked. The blank template is supposed to fail until the goal, the owner, the budget left, the constraints, and the acceptance criteria are filled in. python3 demo_handoff.py shows a sloppy handoff failing, then the repaired one passing. The same check and template operations are a local MCP server: python3 handoff_checker.py serve.
